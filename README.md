# N2J TRINI — 브랜드 랜딩 스튜디오

브랜드 폼, 카페·학원·네일샵 템플릿 편집, PC/모바일 미리보기, 코드 복사와 HTML 저장을 제공합니다. **실제 AI 생성·서버 저장은 연결되지 않았습니다.** 폼 입력은 탭 안에서만 사용합니다.

## 파일

- `index.html`: CSS와 실행 코드를 포함한 단일 HTML. 다운로드 후 브라우저에서 열 수 있습니다.
- `examples/cafe.html`, `academy.html`, `nail.html`: 직접 작성한 가상 브랜드 예시.
- `src/app/workbench.tsx`: 화면과 문구 수정.
- `src/src/presets.ts`: 예시의 문구·HTML·CSS 수정.
- `styles.css`: 서비스 화면 스타일. 기존 앱의 컴파일된 CSS와 편집용 스타일입니다.

## 수정하고 공유하기

저장소 소유자는 GitHub에서 위 소스 파일을 열어 연필 버튼으로 수정하고 `main`에 커밋할 수 있습니다. Pages 작업이 성공하면 같은 공개 주소에 반영됩니다. 다른 사람은 저장소를 포크하거나 변경 제안을 보낼 수 있으며, 직접 편집하려면 소유자가 협업자로 초대해야 합니다.

로컬에서는 Node 24 이상에서 `npm ci` 후 `npm run build`로 `index.html`과 예시를 다시 만듭니다. 생성된 HTML만 직접 수정하면 다음 빌드에서 덮어쓰므로 소스를 수정하세요.

Google Drive의 HTML은 업로드 시점의 사본입니다. GitHub 변경과 자동 동기화되지 않습니다. 갱신할 때 새로 빌드한 HTML을 같은 Drive 파일의 새 버전으로 올리면 링크를 유지할 수 있습니다.

## 범위

이 저장소에는 공개 프런트엔드와 가상 예시만 있습니다. worker, 서버 프롬프트, 환경변수, 비공개 작업 데이터, 인증정보는 포함하지 않습니다. 실제 아임웹 설치·AI 생성 품질·운영 승인을 증명하는 배포가 아닙니다.

의존성 라이선스 고지는 `THIRD_PARTY_NOTICES.txt`와 번들 내 주석에 보존합니다.
